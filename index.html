The talk in four moves

Translated from the original bilingual Google Slides deck into an English GitHub Pages presentation.

01

The discipline shift

Software engineering specifies testable behavior. Harness engineering puts a deterministic control plane around probabilistic agents.

02

The Core Four

Prompt, context, loop, and graph. Graph engineering governs multi-agent nodes, edges, and handoffs.

03

Control plane

Automation, identity, memory, observability, runtime control, evaluation, scalability, and token budget.

04

Extensions

Skills, plug-ins, MCP, hooks, and CLI. Inventory, least privilege, typed actions, revoke on policy failure.
